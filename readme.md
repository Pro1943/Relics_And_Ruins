# Relics And Ruins

### CLI-based Story and RPG style game

> [!TIP]
> **DEVELOPMENT STATUS**
> This project is in very early development.

---

## Objective

Make a simple CLI-based RPG style game that is story-focused and fun.

### Learning Objective

This project is also set up as a learning project to learn file and data manipulation, gaming logic implementation, and a lot of other things using `Python 3.14.3`.

---

## Contribution Information

### Step 0
Install `Python 3.14` from the official link and set up your IDE.

---

### Step 1
Clone this repo using:
```bash
git clone https://github.com/Pro1943/Relics_And_Ruins
```    
Then open the folder in your IDE.

---

### Step 2
Run the following command to install all dependencies:
```bash
pip install -r requirements.txt
```
and wait for the installation to finish.

---

### Step 3
Create a new branch for your changes:
```bash
git checkout -b feature/your-feature-name
```
Add or change the codebase to implement your new features or bug fixes.

---

### Step 4
Commit and push your completed changes to the repository:
```bash
git add .
git commit -m "Add description of the changes you made"
git push origin feature/your-feature-name
```
Once pushed, open a **Pull Request** on GitHub so your code can be reviewed and merged!
